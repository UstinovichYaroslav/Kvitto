# Kvitto - Система платежей

FastAPI приложение для обработки платежей с поддержкой тарифов, промокодов и рассрочки.

## Способ 1: Запуск с Docker (рекомендуется)

Docker Compose автоматически поднимает PostgreSQL и приложение.

```bash
docker-compose up -d
```

Приложение будет доступно на `http://localhost:8000`

Для остановки:

```bash
docker-compose down
```

## Способ 2: Локальный запуск

### Шаг 1: Установка зависимостей

```bash
uv sync
```

### Шаг 2: Запуск PostgreSQL с Docker

```bash
docker-compose up -d pg
```

### Шаг 3: Настройка базы данных

Скопируйте `.env.template` в `.env`:

```bash
cp .env.template .env
```

Настройте `APP_CONFIG__DB__URL` в `.env` (база уже запущена на порту 5432):

```
APP_CONFIG__DB__URL="postgresql+asyncpg://user:password@127.0.0.1:5432/kvitto"
```

### Шаг 4: Запуск миграций

```bash
cd src
alembic upgrade head
```

### Шаг 5: Запуск приложения

```bash
cd src
uvicorn main:app_main --reload
```

Приложение будет доступно на `http://localhost:8000`

## Технологии

## API Эндпоинты

### Тарифы

#### GET /api/tariffs
Получить список тарифов

**Ответ:** `200` - список тарифов `[{ id, title, price }]`

#### POST /api/tariffs
Создать тариф

**Тело:**
- `title` - название тарифа
- `price` - цена в копейках

**Ответ:** `201` - созданный тариф

#### GET /api/tariffs/{tariff_id}
Получить тариф по id

**Ответ:** `200` - тариф, `404` если не найден

#### PUT /api/tariffs/{tariff_id}
Полное обновление тарифа

**Тело:**
- `title` - название тарифа
- `price` - цена в копейках

**Ответ:** `200` - обновлённый тариф, `404` если не найден

#### PATCH /api/tariffs/{tariff_id}
Частичное обновление тарифа

**Тело:**
- `title` - название тарифа (опционально)
- `price` - цена в копейках (опционально)

**Ответ:** `200` - обновлённый тариф, `404` если не найден

#### DELETE /api/tariffs/{tariff_id}
Удалить тариф

**Ответ:** `204` - удалено, `404` если не найден

### Платежи

#### POST /api/payments
Создать платёж

**Тело:**
- `tariff_id` - id тарифа
- `email` - email пользователя
- `method` - способ оплаты (card, sbp, installment)
- `installment_months` - срок рассрочки (3, 6 или 12) - только для installment
- `promo_code` - промокод (опционально)

**Заголовки:**
- `Idempotency-Key` - ключ идемпотентности (опционально)

**Ответ:** `201` - созданный платёж, `200` если платёж с таким ключом уже существует

#### GET /api/payments/{payment_id}
Получить платёж по id

**Ответ:** `200` - платёж, `404` если не найден

#### PUT /api/payments/{payment_id}
Полное обновление платежа

**Тело:** все поля платежа

**Ответ:** `200` - обновлённый платёж, `404` если не найден

#### PATCH /api/payments/{payment_id}
Частичное обновление платежа

**Тело:** любые поля платежа (опционально)

**Ответ:** `200` - обновлённый платёж, `404` если не найден

#### DELETE /api/payments/{payment_id}
Удалить платёж

**Ответ:** `204` - удалено, `404` если не найден

### Вебхуки

#### POST /api/webhooks/bank
Вебхук от банка для обновления статуса

**Тело:**
- `payment_id` - id платежа
- `status` - новый статус

**Ответ:** `200` - `{ result: "ok" }`, `404` если платёж не найден, `409` если переход статуса недопустим

## Бизнес-логика

### Тарифы
При старте автоматически создаются три тарифа:
- basic — 9 900 ₽ (990000 копеек)
- standard — 19 900 ₽ (1990000 копеек)
- premium — 29 900 ₽ (2990000 копеек)

### Промокоды
- `KVITTO10` — скидка 10% от цены тарифа (регистр не важен)
- Неизвестный промокод — ошибка 422

### Способы оплаты
- `card` — карта
- `sbp` — СБП
- `installment` — рассрочка (обязателен `installment_months`: 3, 6 или 12)

### График рассрочки
Сумма делится на количество месяцев. Лишние копейки распределяются в первые платежи.

Пример для standard (1990000 копеек) на 3 месяца:
```
schedule = [663334, 663333, 663333]  # сумма = 1990000
```

### Статусы платежей
- `pending` — новый платёж
- `succeeded` — успешно оплачен
- `failed` — ошибка оплаты
- `refunded` — возвращён

Допустимые переходы:
- `pending` → `succeeded`
- `pending` → `failed`
- `succeeded` → `refunded`

Остальные переходы запрещены (возвращают 409).
